# 影OS · Kage OS

Un système d'exploitation rétro-futuriste qui tourne entièrement dans le navigateur.
Projet de Gounteni David.

**En ligne : https://kage-os-phi.vercel.app**

## Ce qu'il y a dedans

- Écran de démarrage façon BIOS, effet écran cathodique (CRT) et 4 fonds d’écran (dont une pluie animée)
- Bureau avec fenêtres déplaçables, redimensionnables, agrandissables
- Barre des tâches, menu démarrer, horloge, menu clic droit sur le bureau et notifications
- **Ambiance** : générateur d'ambiance sonore cyberpunk (pluie, orage, vent, ville,
  néons, salle serveur, clavier), 100 % synthétisé avec la Web Audio API, avec
  visualisations en direct (oscilloscope, spectre, géométrie)
- **Terminal** : commandes qui pilotent l'OS (`help`, `open`, `theme`, `crt`,
  `neofetch`…) et quelques easter eggs
- **Fichiers** : gestionnaire de fichiers avec aperçu des textes et images
- **Focus** : minuteur Pomodoro, tâches et statistiques
- **Kanji Quiz** : apprendre 42 kanji courants
- **Lueur** : mini-jeu d'arcade
- **Notes**, **Réglages** et **À propos**

## Stack

React · TypeScript · Vite · Tailwind CSS · Framer Motion · Web Audio API · Canvas 2D

## Lancer le projet

```bash
npm install
npm run dev
```
